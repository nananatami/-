# 一梦动态首屏样稿

网站地址：https://nananatami.github.io/-/

GitHub Pages 从 `main` 分支根目录发布。修改根目录的 `index.html`、`style.css`、`main.js` 或 `assets` 后，提交并推送到 `main` 即会触发更新；无需修改 `dist` 副本。`.nojekyll` 用于直接发布静态文件。

本地预览：运行 `node server.cjs`，打开 http://127.0.0.1:5173 。

黑白 + 克莱因蓝（#002FA7），原创 CSS 3D 翻转网格。自动逐列翻转、指针 / 触碰互动、暂停动态、减少动态偏好、移动端布局。首屏标题为“一梦工作室”，下方是 Design × technology 蓝色介绍区与三项业务能力。

字体：RRPL（首屏标题）、ZSFT-ak（英文介绍标题）、LXGW ZhiSong CL（中文正文）、USMCCyuanjiantecu（业务标题）。`cache-fonts.py` 从用户指定的 ZeoSeven 地址下载当前页面所需字体子集并保留来源中的版权说明；更新文字后可重新运行以补齐新字。

首屏文字按网格切片，随面板绕横轴翻转。第一次向下滚动、向上滑动、按 PageDown 或点击“翻到介绍”会原地翻到蓝色介绍背面，继续滚动才进入业务区。在顶端向上滚动或点击“返回首页”可翻回正面。手机为三列六行，电脑为六列六行；暂停 / 减少动态模式下保留翻面功能并关闭过渡。

首屏之后通过深蓝到浅蓝的渐变衔接七项业务：社区智能运营中台、前端开发与交互设计、多模型 AI 统一网关、AIGC 创作工作台、智能翻译工作流、运动与饮食陪伴助手、网络中继与反向代理工具。技术说明按团队提供的内容展示。各行默认收起；鼠标悬停或点击展开，一次只展开一个项目，再次点击可收起。键盘 Enter / Space 切换展开状态，方向键移动焦点。详情采用左侧介绍、右侧功能流程示意，手机上下排列。暂停与减少动态模式关闭展开过渡。社区成员规模保留最新确认的 62,000 人。
